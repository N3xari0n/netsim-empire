# NetSim Empire 🌐
**Build. Secure. Conquer.**

NetSim Empire is a real-time multiplayer Node.js strategy simulation where you architect global carrier-grade ISP networks, deploy multi-layered defensive firewalls, and fulfill massive enterprise client contracts via a specialized UNIX-like CLI interface.

### Tech Stack
* **Frontend:** Vanilla JS, HTML5 Canvas Rendering
* **Backend:** Node.js, Express, SQLite Database
* **Authentication:** 12-Layer Backup-Code Hashing, bcrypt Security

### Disclaimer
This repository does not encompass active production `.env` payloads or raw `netsim.db` deployment shards for security reasons.
