### 📡 The Directive
NetSim Empire is a highly-immersive, real-time multiplayer Node.js strategy simulation. You are dropped into an empty terminal with a single objective: **Architect global carrier-grade ISP networks.** 
Deploy localized nodes, construct multi-layered defensive firewalls to block active DDoS arrays, and utilize a specialized UNIX-like CLI interface to manipulate the grid natively.

### ⛓️ Core Systems
* **Multi-Site Engine:** Teleport freely across isolated subnetworks and Enterprise Client domains.
* **Cryptographic Hardening:** 12-Layer Backup-Code hashing, bcrypt authentication locking, and strict SQL persistence.
* **Thermal Flow:** Monitor node strain and raw packet bursts through real-time HSL Heatmaps and Security Radars.

### ⚠️ Security Clearance
This public archive has been sanitized. It explicitly drops active production `.env` payloads and raw local `/netsim.db` deployment shards to prevent cryptographic contamination.
